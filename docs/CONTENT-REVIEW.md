# Content authoring and review

`tools/generate_content.py` produces the reproducible English starter development pack. Each activity has an ID, game/subject/skill, year, objective/reference, difficulty, prerequisites, question type, choices/answer, explanation, progressive hints, status and version. The manifest pins the exact bundle bytes by SHA-256.

Statuses: Draft → Automated Validation Passed → Awaiting Teacher Review → Approved, or Rejected. Retired versions remain in historical evidence but are excluded from selection. Automated validation never implies pedagogical approval. The generator creates Awaiting Teacher Review items; it never creates Approved content.

References are selected objective pointers based on the [DfE mathematics programme](https://www.gov.uk/government/publications/national-curriculum-in-england-mathematics-programmes-of-study/national-curriculum-in-england-mathematics-programmes-of-study) and [DfE English programme](https://www.gov.uk/government/publications/national-curriculum-in-england-english-programmes-of-study/national-curriculum-in-england-english-programmes-of-study). The objective summaries and URL fragments need teacher checking. England alignment does not establish alignment with Scotland, Wales or Northern Ireland. Some reasoning material is explicitly enrichment.

Review every prompt, correct answer, distractor, hint, worked example, narration, prerequisite and age/difficulty assignment. In particular, higher-year arithmetic currently includes warm-up material and reading passages repeat by key-stage band. A reviewer must not infer full curriculum coverage from the presence of year tags.

A human supplies a review JSON with `reviewer`, `qualifications`, `reviewedAt`, `evidence`, `packSha256` and `status` (Approved/Rejected). `python tools/review_content.py record-review --review-file <file>` validates and records that supplied evidence without changing the pack. Completed records are stored privately at `%USERPROFILE%/.skillsprout/content-reviews`, outside the public checkout. A publisher-controlled release update then applies only the actually approved activity IDs, increments the version and regenerates its manifest. No reviewer names or endorsements are provided by this repository.

The interactive review desk is generated with `python tools/prepare_release_review.py` and served locally by `python tools/serve_review.py` at `http://127.0.0.1:4180/release/review-kit/index.html`. It shows the exact 444-item pack in pages of 12, with year filters and private JSON export/import for resuming work. All decisions start Pending. Completed per-item reviews must cover each ID exactly once; pack approval is rejected while any item remains unreviewed or rejected. A changed pack hash invalidates the review. The desk never changes pack status or gate approvals by itself. Keep downloaded personal review files outside Git. It also links the proposed connected-edition privacy notice and the remaining publisher/device/language actions.

Prerequisites use stable skill IDs. The engine supports a prerequisite mastery check; the generated starter list is empty pending authoring. Content ID reuse for a different learning item is forbidden. Deleting an optional pack preserves attempt history and does not erase skill evidence.

21 October 2026: the publisher accepted twelve individual Year 1 logic hint corrections through the guided review. These second-hint changes are applied reproducibly by the content generator; the starter pack and revised items are version 3, while all other items remain version 2. `release/year1-hint-corrections.json` records the before/after text and source/result pack hashes. The private working review retains the individual decisions outside Git. These wording decisions do not supply the still-missing reviewer qualification/experience details, complete-pack approval or other production release evidence; no activity status or evidence gate was promoted to Approved. The regenerated review form binds to the new pack hash, so an older exported form cannot be imported unchanged.
