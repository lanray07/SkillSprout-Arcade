# SkillSprout design system

Concept source: `concepts/arcade-and-site.png`, generated with the built-in imagegen tool. Production assets: `originals/pip.png`, `originals/sproutland.png`. These are original generated assets, not endorsements or licensed franchise characters. The working name still needs clearance.

Cream canvas #FFF9EE, forest text #173F32, leaf action #427C39 (web action #488B37), gold #F4C567. Game surfaces: #D9EABD, #FFD786, #BEE4F1, #F9C6B6, #E0CEF9, #FFE5A8. Parent content uses calm green surfaces. Text is code-native and readable. Decorative world art never encodes essential instructions.

The primary app screen uses a 170dp left navigation rail on wide tablets, a native world illustration with Pip, four district labels and six game choices. Smaller screens stack content and expose Home/Missions/Rewards beneath it. Titles are 32sp, secondary headings 23sp, body 16–21sp; primary actions have a 52dp minimum height and outlined controls 48dp. Corners are 18–26dp. Motion moves Pip after a correct maths answer and obeys the profile's reduced-motion setting.

The website follows the concept's cream backdrop, green two-line wordmark, three-link navigation, left headline, green CTA and right world/Pip artwork. The main text follows the supplied tagline exactly. Accurate development disclosures replace the concept's implication of a launched product. Dedicated editorial pages share the same typography and artwork. Mobile art is stacked below the copy. No fictional stats, reviews, endorsements or store availability appear.
