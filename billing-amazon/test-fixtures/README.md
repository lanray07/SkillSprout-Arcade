# App Tester catalogue

These are the two owned SkillSprout subscription-term fixtures, based on the console export and the earlier sandbox catalogue. Prices are synthetic test inputs (4.99 and 29.99 for US/GB test marketplaces). They do not change or verify live store prices, trial eligibility or marketplace conversions. The accepted UK draft prices remain £4.99/month and £29.99/year.

The Fire runner merges these entries into the existing device catalogue temporarily, preserves unrelated products, opens App Tester, and restores the exact original bytes afterward. It detects concurrent catalogue changes and preserves those changes while removing/restoring only SkillSprout entries; that situation is reported as an inconclusive run rather than a clean restoration.

No real account identifiers, receipts, private keys or developer shared secret are included. A catalogue alone does not create an active purchase. Empty receipt restoration is not valid-purchase proof.
